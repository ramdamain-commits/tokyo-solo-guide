# 東京ひとり遊びガイド

東京で一人で楽しめる文化・歴史スポットと、今月の企画展・季節の見頃・休館情報をまとめた汎用ガイド。

🔗 公開URL: https://ramdamain-commits.github.io/tokyo-solo-guide/

## 構成
- `index.html` / `app.js` — サイト本体（JSON を読み込んで描画）
- `data/evergreen.json` — 常設スポット（歴史・観戦・自然・グルメ・体験・伝統芸能・銭湯サウナ温泉）
- `data/monthly.json` — 今月の企画展・歳時/祭り・季節・休館（月次更新）
- `data/sources.json` — 調査に使う承認済みソース一覧
- `docs/UPDATING.md` — 月次更新の手順

## 更新方法
月初に `docs/UPDATING.md` の手順で `data/monthly.json` を差し替える。詳細は同ファイル参照。

## 雨の日の可否（`rain`）
各項目（常設・企画展・歳時/祭り・季節）に `rain` を付け、名前の横に ☔バッジで表示する。休館情報には付けない。未設定の項目はバッジを出さない。

| 値 | 表示 | 基準 |
|----|------|------|
| `ok` | ☔可 | 屋内で完結する（美術館・博物館・寄席・屋内の温浴施設・展望室など） |
| `caution` | ☔非推奨 | 雨でも成立するが屋外が主体で魅力が落ちる（庭園・渓谷・花の見頃・雨天決行の祭り・屋根付きスタンドのある競馬など） |
| `ng` | ☔不可 | 雨で中止になる、または成立しない（屋外の野球観戦・公式に雨天中止とある行事など） |

## 方針
公開リポのため、居住地・予算・個人属性は一切含めない汎用情報のみを掲載する。
